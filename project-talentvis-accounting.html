Internal Accounting System —
Technical Documentation

Created the FSD and TSD documentation from scratch for an existing company-wide finance web application — turning knowledge held only by the development team into a written, reusable reference.

01 Overview

The Internal Accounting System at Talentvis Singapore LTE is a web application used to record all finance activity within the company. The system had been running for a while with no formal documentation at all. I produced the missing FSD (Functional Specification Document) and TSD (Technical Specification Document) from scratch, gathering every detail directly from the technical team.

02 The Problem

The system was operational but completely undocumented. No FSD, TSD, or user guide existed describing how it worked or how its finance processes were executed. The company depended entirely on the knowledge of the people who built and managed the application.

03 My Role

  • Studied and understood the existing accounting system to capture how it functions.
  • Produced an FSD describing the system's functionality and streamlined finance processes.
  • Produced a TSD describing the technical implementation.
  • Assisted in checking the system for potential bugs as part of the QA effort.

04 Process

I obtained information directly from the Technical Lead, the Senior Developer who built and managed the application, and QA. From that collaboration, I reconstructed how the system works and documented every stage of the finance workflow in a structured, written form.

05 Solution & Deliverables

  • FSD (Functional Specification Document): the functional blueprint covering the system's features and streamlined finance processes.
  • TSD (Technical Specification Document): technical detail for how the system is implemented.

06 Outcome

The documentation was completed and completely helped the team — providing the company with a written reference for the accounting system where none existed before.

07 Lessons Learned

Reconstructing an understanding of an undocumented system is possible through structured stakeholder collaboration. The finance domain demands accuracy in documentation, and the role gave me practical exposure to both technical writing and quality assurance.
